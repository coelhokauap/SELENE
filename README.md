# SELENE - Monitoramento Ambiental

Interface estática desenvolvida para a entrega de Front-End Design da FIAP. O SELENE é uma plataforma de monitoramento ambiental que utiliza dados orbitais simulados para acompanhar riscos climáticos, emitir alertas, registrar ocorrências e apoiar decisões de órgãos públicos, agricultores e equipes de emergência.

## Problema Resolvido

Eventos como queimadas, enchentes, secas e deslizamentos exigem resposta rápida. O SELENE propõe uma interface que organiza dados de satélites, sensores e modelos preditivos em um dashboard acessível, permitindo que usuários acompanhem regiões críticas, visualizem telemetria ambiental e simulem cenários de risco.

## Estrutura da Interface

O HTML foi organizado com tags semânticas como `header`, `nav`, `main`, `section`, `article`, `figure`, `aside` e `footer`. Essa estrutura melhora a acessibilidade, facilita a navegação por leitores de tela e separa claramente os módulos da solução:

- Dashboard de indicadores ambientais
- Monitoramento de eventos críticos
- Alertas e preferências de notificação
- Mapa de regiões monitoradas
- Telemetria de fontes orbitais
- Histórico de ocorrências
- Simulação e previsão de riscos
- Administração de usuários, permissões e logs
- Educação ambiental

## Escolhas Visuais

As cores combinam tons claros com azul e roxo para representar tecnologia espacial, dados orbitais e confiabilidade. O azul foi usado como cor principal por transmitir segurança e precisão, enquanto o roxo reforça a conexão com inovação e indústria espacial. Os tons de status destacam criticidade: vermelho para alertas críticos, amarelo para atenção e verde para estabilidade.

A tipografia utiliza `Segoe UI` e fontes de sistema para garantir boa legibilidade, aparência moderna e compatibilidade entre navegadores. O layout usa grids, cards e hierarquia visual clara para facilitar a leitura de dados de missão crítica.

## Usabilidade

A interface prioriza leitura rápida de informações: indicadores grandes, cards agrupados por função, tabela de telemetria, filtros, simulação de cenários e histórico operacional. Os formulários têm labels, campos obrigatórios e foco visual, melhorando a experiência de uso e a acessibilidade.

## Arquivos

- `index.html`: estrutura semântica da interface.
- `style.css`: identidade visual, layout responsivo e componentes.
- `script.js`: interações simuladas para login, dashboard, registro de ocorrências, simulação, relatórios e preferências.
