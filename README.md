# SELENE – Monitoramento Ambiental Orbital

# Front-End Design

## Descrição do Projeto

A Plataforma SELENE é uma solução tecnológica desenvolvida para monitoramento ambiental utilizando dados orbitais e sensoriamento remoto. O sistema tem como objetivo auxiliar órgãos públicos, agricultores, pesquisadores e equipes de emergência na identificação precoce de riscos ambientais, como queimadas, enchentes, secas e deslizamentos.

A proposta está alinhada ao desafio da Global Solution 2026, utilizando tecnologias inspiradas na Indústria Espacial para transformar dados de satélites em informações estratégicas para tomada de decisão.

---

# Problema que a Interface Busca Resolver

Atualmente, grande parte das informações ambientais encontra-se distribuída em diferentes plataformas, dificultando o acesso rápido a dados críticos durante situações de emergência.

A interface SELENE foi projetada para centralizar informações provenientes de dados orbitais, permitindo:

- Monitoramento em tempo real de eventos ambientais;
- Visualização geográfica de áreas de risco;
- Geração de alertas automáticos;
- Consulta de dados históricos;
- Simulação de cenários ambientais;
- Apoio à tomada de decisão baseada em dados.

---

# Estrutura da Interface

A estrutura foi organizada em módulos funcionais para facilitar a navegação dos usuários:

### Dashboard

Apresenta indicadores ambientais, métricas operacionais e tendências de risco.

### Monitoramento

Permite acompanhar eventos críticos em tempo real.

### Alertas

Exibe notificações classificadas por nível de criticidade.

### Mapa Interativo

Representa visualmente regiões monitoradas por satélites e sensores.

### Telemetria

Apresenta informações recebidas de diferentes fontes orbitais.

### Histórico

Disponibiliza registros e ocorrências anteriores para consulta.

### Simulação

Permite prever cenários ambientais futuros com base em variáveis configuráveis.

### Administração

Gerencia usuários, permissões e métricas do sistema.

### Educação Ambiental

Disponibiliza conteúdos educativos relacionados à prevenção de desastres e sustentabilidade.

# Justificativa das Cores

A identidade visual da plataforma foi desenvolvida para transmitir tecnologia, confiabilidade e inovação.

### Azul (#4F7CFF)

Cor principal da interface, associada à tecnologia, segurança e monitoramento.

### Roxo (#7C3AED)

Representa inovação, ciência e conexão com o universo espacial.

### Ciano (#00D4FF)

Utilizado como cor de destaque para representar dados orbitais e comunicação digital.

### Branco e Tons Claros

Utilizados para melhorar a legibilidade das informações e criar contraste visual adequado.

---

# Justificativa da Tipografia

Foi utilizada a família tipográfica:

**Segoe UI, system-ui, sans-serif**

A escolha foi realizada por apresentar:

- Excelente legibilidade;
- Aparência moderna;
- Compatibilidade entre navegadores;
- Boa experiência em dispositivos móveis e desktops.

---

# Usabilidade

A interface foi desenvolvida com foco na experiência do usuário, utilizando:

- Navegação simples e intuitiva;
- Hierarquia visual clara;
- Componentes reutilizáveis;
- Layout responsivo;
- Organização modular das informações;
- Elementos visuais que facilitam a interpretação dos dados ambientais.

---

# Relação com a Indústria Espacial

A Plataforma SELENE utiliza o conceito de monitoramento baseado em dados orbitais, aproveitando informações provenientes de satélites para identificação de riscos ambientais.

Essa abordagem está diretamente relacionada ao uso de tecnologias espaciais aplicadas à solução de problemas terrestres, contribuindo para:

- ODS 9 – Inovação e Infraestrutura;
- ODS 11 – Cidades e Comunidades Sustentáveis;
- ODS 13 – Ação Contra a Mudança Global do Clima.
